Computational Biomechanics · Machine Learning

Bone Fracture Prediction

Developed a machine-learning framework utilizing finite element modeling to simulate bone stress distributions and predict patient-specific fracture risk.

FEMXGBoostMATLAB
Project overview

I helped create a large patient-specific dataset and ran FEM simulations under varied loading conditions. These results were combined with patient-specific data to support fracture-risk prediction and improve insight for clinical diagnosis and treatment planning.

XGBoost results: 88% accuracy · 97% confidence · 90.91% precision

04

Biomedical Instrumentation · Signal Analysis

Wireless ECG Signal Quality Analysis

Created a 3-lead benchtop ECG testing system to evaluate signal transmission quality between electrodes at controlled distance intervals from 1” to 24”.

ECGInstrumentationSignal Analysis
Project overview

The setup used a sodium chloride solution container to allow electrical activity, with a signal generator positioned between three electrodes to detect the transmitted activity. Results showed that signal transmission quality improves as distance decreases, supporting future work in wireless ECG development.

My contribution came largely from the ideation and creation of the benchtop model.
